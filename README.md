# xadof
Depth of field helper for 35mm Camera Olympus XA

Currently optimized for iPhone 17 pro max.
- Open https://pixelpampe.github.io/xadof in Safari
- Klick on Share Button in Browser
- Show on Homescreen

If once opend, it should work offline
